# XML-сериализатор на рефлексии (Java + JavaFX)

Лабораторная работа 2. Универсальный сериализатор и десериализатор объектов произвольного класса в XML.
Работает через рефлексию и аннотацию `@XmlField`. Поддерживает ссылки (общие объекты, циклы) и массивы ссылок.

## Требования

- Java 21 (JDK)
- Maven 3.8+
- Интернет при первой сборке (Maven скачает JavaFX)

Установка на Fedora:

```bash
sudo dnf install java-21-openjdk-devel maven
```

## Запуск

Из корня проекта (где лежит `pom.xml`):

```bash
mvn javafx:run
```

## Интерфейс

```
+--------------------------------------------------------------+
| Класс: [demo.Person        ] [Создать по имени класса] [Демо-граф] |
+------------------------------+-------------------------------+
| TreeView объекта (слева)     | XML (справа)                  |
+------------------------------+-------------------------------+
| [Сериализовать →] [← Десериализовать]   статус               |
+--------------------------------------------------------------+
```

| Элемент | Что делает |
|---|---|
| Поле «Класс» + «Создать по имени класса» | Создает пустой объект указанного класса (нужно полное имя, например `demo.Person`) |
| «Демо-граф» | Загружает готовый пример: два человека со ссылками друг на друга, общий адрес, массивы |
| Дерево слева | Показывает объект. Простые значения (числа, строки, enum, boolean) правятся двойным кликом, Enter сохраняет, Esc отменяет |
| «Сериализовать →» | Превращает текущий объект из дерева в XML справа |
| «← Десериализовать» | Читает XML справа и строит объект и дерево слева |
| Статус внизу | `OK` или текст ошибки |

Обозначения в дереве:

- `имя = значение` : простое значение
- `имя : Класс #N` : объект с номером N (совпадает с `id` в XML)
- `имя → #N` : повторная ссылка на уже показанный объект
- `имя = null` : пустая ссылка

Типичный сценарий:

1. Нажать «Демо-граф».
2. Изменить значение в дереве (например, возраст), нажать «Сериализовать →».
3. Отредактировать XML справа руками, нажать «← Десериализовать» и посмотреть дерево.

## Формат XML

Пример для демо-графа:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root id="1" type="demo.Person" age="30">
  <name>Alice</name>
  <address id="2" type="demo.Address">
    <city>Riga</city>
    <street>Brivibas 1</street>
  </address>
  <friend id="3" type="demo.Person" age="25">
    <name>Bob</name>
    <address idref="2"/>
    <friend idref="1"/>
    <team nil="true"/>
    <scores nil="true"/>
  </friend>
  <team id="4" type="[Ldemo.Person;">
    <item idref="1"/>
    <item idref="3"/>
    <item nil="true"/>
  </team>
  <scores id="5" type="[I">
    <item>5</item>
    <item>4</item>
    <item>5</item>
  </scores>
</root>
```

| Атрибут | Значение |
|---|---|
| `id` | Номер объекта или массива. Каждый объект пишется один раз |
| `idref` | Ссылка на ранее записанный объект с этим `id` (так записываются общие объекты и циклы) |
| `type` | Полное имя класса (для массивов в JVM-форме: `[I`, `[Ldemo.Person;`) |
| `nil="true"` | Значение `null` |

Корневой элемент всегда называется `root`. Класс объекта при десериализации берется из его `type`.

## Как подключить свой класс

1. Положите класс в `src/main/java/...`.
2. Добавьте публичный или приватный конструктор без аргументов.
3. Пометьте нужные поля `@XmlField`.

```java
public class Book {
    @XmlField public String title;
    @XmlField(attribute = true) public int year;   // запись атрибутом
    @XmlField(name = "writer") public Person author; // другое имя тега
    @XmlField public Book[] related;               // массив ссылок

    public Book() {}
}
```

4. В GUI введите полное имя класса (`pkg.Book`) и нажмите «Создать по имени класса».

Параметры `@XmlField`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `name` | имя поля | Имя тега или атрибута в XML |
| `attribute` | `false` | Писать как атрибут. Только для простых типов |

Использование из кода:

```java
String xml = XmlSerializer.serialize(obj);
Object o1 = XmlSerializer.deserialize(xml);
Book o2 = XmlSerializer.deserialize(xml, Book.class);
```

## Что поддерживается

- Простые типы: примитивы и их обертки, `String`, `enum`
- Объекты классов с `@XmlField`, включая поля родительских классов
- Массивы любой вложенности, в том числе массивы ссылок
- Общие объекты и циклические ссылки (`id` / `idref`)
- `null`

## Ограничения

- Сериализуются только поля с `@XmlField`. Остальные игнорируются
- Нужен конструктор без аргументов
- `List`, `Map` и другие коллекции не поддерживаются
- Поля `static` не сериализуются
- В GUI нельзя создать вложенные объекты через дерево. Используйте «Демо-граф» или правьте XML справа
- Для безопасности `DOCTYPE` в XML запрещен

## Типичные ошибки

| Сообщение | Причина |
|---|---|
| `ClassNotFoundException` | Неверное полное имя класса (нужен пакет, например `demo.Person`) |
| `Нет полей с @XmlField` | У класса нет аннотированных полей |
| `NoSuchMethodException` | Нет конструктора без аргументов |
| `Неизвестный idref=N` | В XML ссылка на `id`, которого нет выше по документу |
| `NumberFormatException` | Неверное число в дереве или XML |
