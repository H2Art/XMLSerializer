# XML-сериализатор на рефлексии (Java + JavaFX)

Лабораторная работа 2. Универсальный сериализатор и десериализатор объектов произвольного класса в XML.
Работает через рефлексию и аннотацию `@XmlField`. Поддерживает ссылки (общие объекты, циклы) и массивы ссылок.

## Требования

- Java 21 (JDK)
- Maven 3.8+
- Интернет при первой сборке (Maven скачает JavaFX и JUnit)

Установка на Fedora:

```bash
sudo dnf install java-21-openjdk-devel maven
```

## Запуск

Из корня проекта (где лежит `pom.xml`):

```bash
mvn javafx:run
```

Тесты:

```bash
mvn test
```

## Интерфейс

```
+------------------------------------------------------------------+
| Класс: [demo.Person ] [Создать по имени класса] [Демо-граф]      |
+---------------------------------+--------------------------------+
| TreeView объекта (слева)        | XML (справа)                   |
+---------------------------------+--------------------------------+
| [Сериализовать →] [← Десериализовать]   статус                   |
+------------------------------------------------------------------+
```

| Элемент | Что делает |
|---|---|
| «Создать по имени класса» | Создает пустой объект класса из поля «Класс» (полное имя, например `demo.Person`) |
| «Демо-граф» | Загружает пример: два человека со ссылками друг на друга, общий адрес, массивы |
| «Сериализовать →» | Превращает объект из дерева в XML справа |
| «← Десериализовать» | Читает XML справа и строит объект и дерево слева |
| Статус внизу | `OK` или текст ошибки |

### Дерево объекта

Обозначения:

| Запись | Значение |
|---|---|
| `имя = 5` | простое значение |
| `имя = "текст"` | строка (`""` это пустая строка) |
| `имя = null` | пустая ссылка |
| `имя : Класс #N` | объект с номером N (совпадает с `id` в XML) |
| `имя : int[3] #N` | массив с номером N |
| `имя → #N` | повторная ссылка на уже показанный объект |

### Редактирование

**Двойной клик** по простому значению (число, строка, `boolean`, `char`, `enum`): ввод нового значения, Enter сохраняет, Esc отменяет. Неверный ввод покажет ошибку, значение не изменится.

**Правый клик** по узлу (кроме корня) открывает меню:

| Узел | Пункт меню | Что делает |
|---|---|---|
| Любое непримитивное значение, не `null` | «Установить null» | Записывает `null` в поле или элемент массива |
| `null`-ссылка на объект | «Создать объект...» | Диалог с именем класса. Для конкретного типа поля имя подставлено, можно вписать подкласс |
| `null`-массив или `null`-элемент типа массива | «Создать массив...» | Диалог с длиной (0 до 10000), создается пустой массив нужного типа |

Правила:

- Строка `""` и `null` разные значения. Чтобы вернуть строку в `null`, используйте «Установить null».
- Для интерфейса, абстрактного класса и `Object` имя класса вводится вручную. Класс должен подходить к типу поля и иметь поля `@XmlField`.
- Примитивы нельзя установить в `null`, пункта меню для них нет.
- Размер уже созданного массива изменить нельзя. Чтобы получить другую длину: «Установить null», затем «Создать массив...».
- После изменений дерево перестраивается, номера `#N` пересчитываются.

### Работа с массивами

| Элемент массива | Что делать |
|---|---|
| Примитив или `String` | Двойной клик, ввести значение |
| `null`-элемент типа объекта | Правый клик, «Создать объект...» |
| `null`-элемент типа массива (строка `int[][]`) | Правый клик, «Создать массив...» |

Имена типов массивов в XML (атрибут `type`) записаны в форме JVM, вводить их руками не нужно:

| Тип | Имя в XML |
|---|---|
| `int[]` | `[I` |
| `int[][]` | `[[I` |
| `String[]` | `[Ljava.lang.String;` |
| `Person[]` | `[Ldemo.Person;` |

### Типичный сценарий

1. Нажать «Демо-граф».
2. У Alice правый клик на `address`, «Установить null», затем снова правый клик, «Создать объект...», `demo.Address`, заполнить `city` и `street`.
3. Нажать «Сериализовать →», посмотреть XML.
4. Изменить XML справа руками, нажать «← Десериализовать», проверить дерево.

## Формат XML

Пример для демо-графа:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root id="1" type="demo.Person" age="30">
  <name>Alice</name>
  <address id="2" type="demo.Address">
    <city>Riga</city>
    <street>Brivibas 1</street>
  </address>
  <friend id="3" type="demo.Person" age="25">
    <name>Bob</name>
    <address idref="2"/>
    <friend idref="1"/>
    <team nil="true"/>
    <scores nil="true"/>
  </friend>
  <team id="4" type="[Ldemo.Person;">
    <item idref="1"/>
    <item idref="3"/>
    <item nil="true"/>
  </team>
  <scores id="5" type="[I">
    <item>5</item>
    <item>4</item>
    <item>5</item>
  </scores>
</root>
```

| Атрибут | Значение |
|---|---|
| `id` | Номер объекта или массива. Каждый объект пишется один раз |
| `idref` | Ссылка на ранее записанный объект с этим `id` (общие объекты и циклы) |
| `type` | Полное имя класса. Для простых значений пишется, только если отличается от объявленного типа поля |
| `nil="true"` | Значение `null` |

Корневой элемент всегда `root`. Класс корневого объекта берется из его `type`. Поля читаются в порядке объявления в классе, поэтому при ручной правке `id` должен идти раньше своего `idref` в порядке обхода.

## Как подключить свой класс

1. Положите класс в `src/main/java/...`.
2. Добавьте конструктор без аргументов (может быть приватным).
3. Пометьте нужные поля `@XmlField`.

```java
public class Book {
    @XmlField public String title;
    @XmlField(attribute = true) public int year;     // запись атрибутом
    @XmlField(name = "writer") public Person author; // другое имя тега
    @XmlField public Book[] related;                 // массив ссылок

    public Book() {}
}
```

4. В GUI введите полное имя (`pkg.Book`) и нажмите «Создать по имени класса».

Параметры `@XmlField`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `name` | имя поля | Имя тега или атрибута в XML |
| `attribute` | `false` | Писать как атрибут. Только для простых типов, имя не должно быть `id`, `idref`, `type`, `nil` |

Использование из кода:

```java
String xml = XmlSerializer.serialize(obj);
Object o1 = XmlSerializer.deserialize(xml);
Book o2 = XmlSerializer.deserialize(xml, Book.class);
Book o3 = XmlSerializer.deserialize(xml, "pkg.Book");
```

## Тесты

JUnit 5, файл `src/test/java/xml/XmlSerializerTest.java`, 30 тестов:

| Группа | Что проверяется |
|---|---|
| Значения | Примитивы, обертки, `String`, `enum`, unicode, `null`, пустая строка, пробелы, спецсимволы XML |
| Ссылки | Общий объект остается одним экземпляром, циклы, массив со ссылкой на владельца, `id` и `idref` в XML |
| Структура | Поля родителя, `attribute` и `name`, игнор полей без аннотации, массивы (`int[]`, `int[][]`, `String[]`, `Node[]`), полиморфизм, идемпотентность |
| API | `deserialize` по `Class` и по имени класса |
| Ошибки | `null`, класс без `@XmlField`, неверный `attribute`, неизвестный `idref` и класс, плохое число и `boolean`, нет конструктора, битый XML, `DOCTYPE`, нет `type` |

Интерфейс JavaFX тестами не покрыт, его проверяют вручную.

## Что поддерживается

- Простые типы: примитивы и их обертки, `String`, `enum`
- Объекты классов с `@XmlField`, включая поля родительских классов и подклассы в полях родительского типа
- Массивы любой вложенности, в том числе массивы ссылок
- Общие объекты и циклические ссылки (`id` / `idref`)
- `null`

## Ограничения

- Сериализуются только поля с `@XmlField`. Остальные и `static` игнорируются
- Нужен конструктор без аргументов
- `List`, `Map` и другие коллекции не поддерживаются
- Внутренние (не `static`) классы, `record` и `enum` с телом констант не поддерживаются
- Символы, недопустимые в XML 1.0 (например, `\0`), дают некорректный XML
- Очень глубокая цепочка объектов (тысячи звеньев) приведет к `StackOverflowError`
- Поле типа `Object` в GUI нельзя заполнить простым значением, только объектом класса с `@XmlField`
- Для безопасности `DOCTYPE` в XML запрещен

## Типичные ошибки

| Сообщение | Причина |
|---|---|
| `ClassNotFoundException` | Неверное полное имя класса (нужен пакет, например `demo.Person`) |
| `Нет полей с @XmlField` | У класса нет аннотированных полей |
| `NoSuchMethodException` | Нет конструктора без аргументов |
| `Неизвестный idref=N` | В XML ссылка на `id`, которого нет выше по порядку обхода |
| `NumberFormatException` | Неверное число в дереве или XML |
| `... не подходит к типу ...` | Выбранный класс не наследует тип поля |
